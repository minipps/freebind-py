# API reference

The core API is exported from `freebind`. Integration adapters live in separate
modules and require their matching optional dependency (`freebind-py[requests]`,
`freebind-py[aiohttp]`, `freebind-py[httpx]`, or `freebind-py[curl-cffi]`).
